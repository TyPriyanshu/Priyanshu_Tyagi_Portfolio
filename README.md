# Priyanshu Tyagi Portfolio

A modern, responsive portfolio website built using React, TypeScript, Vite, and Tailwind CSS.

## Features

- Responsive design
- Dark/Light mode
- Projects showcase
- Skills and Experience
- Certificates
- Contact section

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
